Documentación y Análisis de Código Simplificado

Lectorcito Pro es la herramienta definitiva para desarrolladores que necesitan consolidar proyectos complejos en un solo archivo de texto. Ideal para crear contextos para Inteligencia Artificial (LLMs), auditorías de código y documentación técnica.

Flujo de Trabajo Sugerido

Sigue estos 3 pasos para obtener el mejor resultado.

1

Configura los Filtros

Antes de leer, ve a la barra lateral. Usa "Qué No Ver" para excluir carpetas pesadas (como node_modules o venv) y "Qué Ver" para asegurar que lees las extensiones correctas (.py, .js, .html).

2

Selecciona y Genera

Presiona "Generar Lectura Completa". Selecciona la carpeta raíz de tu proyecto. Lectorcito escaneara recursivamente todo el contenido.

3

Resultados Listos

El reporte se guardará automáticamente. Usa el botón "Abrir Último Reporte" para ver el archivo `.txt` consolidado y listo para copiar a tu IA favorita.

Menú Principal

Explicación detallada de las 6 funciones centrales de la aplicación.

1. Seleccionar Destino

Por defecto, los reportes se guardan dentro de la aplicación. Con este botón puedes elegir una carpeta externa personalizada (ej: Escritorio o Documentos) para que todos tus reportes se guarden allí.

2. Generar Lectura Completa

La función principal. Abre un selector para elegir la carpeta de tu proyecto. Analiza archivos, ignora lo configurado en los filtros y crea un archivo único con todo el código fuente.

3. Crear Estructura de Árbol

No lee el contenido de los archivos. Solo genera un diagrama visual de la jerarquía de carpetas y archivos. Muy útil para entender la arquitectura del proyecto sin leer el código.

4. Abrir Carpeta Lecturas

Abre el explorador de archivos de Windows directamente en la carpeta donde se están guardando tus reportes generados.

5. Abrir Último Reporte

Acceso rápido. Abre inmediatamente el archivo `.txt` o `.md` más reciente que hayas generado, ahorrándote tiempo de búsqueda.

6. Eliminar Lecturas

Función de limpieza. Borra todos los archivos dentro de la carpeta de "Lecturas" actual para liberar espacio o reiniciar auditorías.

Barra de Herramientas

Domina la configuración con las 10 herramientas laterales.

Control de Archivos

Qué Ver (Inclusión)

Define explícitamente qué extensiones (.py, .js) y qué carpetas importantes (src) quieres leer. Soporta autodeteción de extensiones.

Qué No Ver (Exclusión)

Crucial para el rendimiento. Bloquea carpetas basura como node_modules, .git o archivos sensibles como .env.

Multimedia (Solo Listar)

Archivos binarios (imágenes, PDFs, ejecutables) que deben aparecer en el reporte para constancia, pero sin intentar leer su contenido ilegible.

Tema

Crea entornos de trabajo. Ejemplo: Un perfil "Python" que ignora venv y lee .py, y otro "Web" que lee .js y .css.
