Flujo de Trabajo Sugerido

Sigue estos 3 pasos para obtener el mejor resultado.

1

Configura los Filtros

Antes de leer, ve a la barra lateral. Usa "Qué No Ver" para excluir carpetas pesadas como node_modules o venv, y "Qué Ver" para asegurar que lees las extensiones correctas.

2

Selecciona y Genera

Presiona "Generar Lectura Completa", selecciona la carpeta raíz de tu proyecto y deja que la aplicación escanee recursivamente todo el contenido permitido.

3

Resultados Listos

El reporte se guardará automáticamente. Luego puedes abrir el último archivo generado o compartirlo directamente como contexto de trabajo para documentación o IA.

Menú Principal

Explicación detallada de las 6 funciones centrales de la aplicación.

1. Seleccionar Destino

Por defecto, los reportes se guardan dentro de la aplicación. Con este botón puedes elegir una carpeta externa personalizada para que todos los reportes se guarden allí.

2. Generar Lectura Completa

La función principal. Abre un selector para elegir la carpeta de tu proyecto, analiza archivos, ignora lo configurado en los filtros y crea un archivo único con todo el código fuente.

3. Crear Estructura de Árbol

No lee el contenido de los archivos. Solo genera un diagrama visual de la jerarquía de carpetas y archivos para entender la arquitectura del proyecto de forma inmediata.

4. Abrir Carpeta Lecturas

Abre el explorador de archivos de Windows directamente en la carpeta donde se están guardando los reportes generados.

5. Abrir Último Reporte

Acceso rápido al archivo más reciente generado, en formato .txt o .md, sin tener que buscarlo manualmente.

6. Eliminar Lecturas

Función de limpieza para borrar todos los archivos dentro de la carpeta de lecturas actual y dejar el espacio listo para un nuevo proceso.

Barra de Herramientas

Configura lectura, exclusiones, perfiles y ajustes del sistema desde un solo lugar.

Control de Archivos

Qué Ver (Inclusión)

Define qué extensiones y carpetas relevantes quieres leer. También soporta autodetección para facilitar la preparación de proyectos nuevos.

Qué No Ver (Exclusión)

Bloquea carpetas basura, archivos sensibles y ahora también puede apoyarse en reglas compatibles con .gitignore para una exclusión más cómoda.

Multimedia (Solo Listar)

Permite dejar constancia de archivos binarios o pesados dentro del reporte sin intentar procesar su contenido.
