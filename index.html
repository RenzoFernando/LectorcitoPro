Consolida proyectos para auditoría, documentación y contexto de IA

Lectorcito Pro es una herramienta de escritorio para desarrolladores que necesitan reunir proyectos complejos en un único reporte TXT o Markdown, con filtros de inclusión, exclusión y manejo de archivos multimedia.

Flujo de trabajo sugerido

Sigue estos tres pasos para preparar un reporte legible y reutilizable.

1

Configura los filtros

Antes de leer, usa Qué No Ver para excluir carpetas pesadas como node_modules o venv, y Qué Ver para definir las extensiones o archivos que sí deben procesarse.

2

Selecciona y genera

Presiona Generar Lectura Completa, selecciona la carpeta raíz del proyecto y deja que la aplicación escanee de forma recursiva el contenido permitido.

3

Usa el resultado

El reporte se guarda automáticamente. Luego puedes abrir el archivo más reciente y usarlo para revisión, documentación o como contexto de trabajo para modelos de IA.

Funciones del menú principal

Las seis acciones centrales cubren selección, lectura, estructura y gestión de reportes.

1. Seleccionar destino

Permite elegir una carpeta externa personalizada para guardar los reportes generados.

2. Generar lectura completa

Es la función principal. Selecciona la carpeta del proyecto, aplica los filtros configurados y crea un archivo único con el contenido permitido.

3. Crear estructura de árbol

Genera una vista de la jerarquía de carpetas y archivos sin leer el contenido de cada archivo.

4. Abrir carpeta de lecturas

Abre el gestor de archivos del sistema directamente en la carpeta donde se guardan los reportes.

5. Abrir último reporte

Accede al archivo más reciente en formato .txt o .md sin buscarlo manualmente.

6. Eliminar lecturas

Borra los archivos de la carpeta de lecturas actual para preparar un nuevo proceso.

Control de archivos

Qué Ver (Inclusión)

Define qué extensiones y carpetas relevantes quieres leer y permite autodetectar reglas para preparar proyectos nuevos.

Qué No Ver (Exclusión)

Excluye carpetas y archivos completos, con apoyo opcional de reglas compatibles con .gitignore.

Multimedia (Solo Listar)

Deja constancia de archivos binarios o pesados dentro del reporte sin intentar procesar su contenido.

Preguntas frecuentes

Respuestas breves sobre alcance, plataformas, filtros y descargas.

¿Qué hace Lectorcito Pro?

Lectorcito Pro analiza proyectos de software de forma recursiva y consolida el contenido relevante en reportes TXT o Markdown para revisión, documentación técnica o uso como contexto para modelos de IA.

¿Qué sistemas operativos admite?

La distribución oficial incluye un instalable y un portable para Windows 10 y 11, además de un binario portable para Linux x86_64.

¿Cómo funcionan Qué Ver y Qué No Ver?

Qué Ver define extensiones y carpetas relevantes para la lectura. Qué No Ver excluye carpetas y archivos completos, y puede apoyarse en reglas compatibles con .gitignore.

¿Qué ocurre con los archivos multimedia o binarios?

La configuración Multimedia permite listar archivos binarios o pesados dentro del reporte sin intentar procesar su contenido.

¿Dónde se descargan las versiones oficiales?

La sección Descargas de este sitio enlaza a los artefactos oficiales publicados en GitHub Releases del proyecto.
